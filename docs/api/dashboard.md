## 1. 工作台数据

```http
GET /api/dashboard
```

**权限**：登录

**计划返回内容**

| 字段 | 说明 |
|---|---|
| `metrics` | 4 个指标：在开发款数、待我处理、逾期任务、本月订单额 |
| `todos` | 我的待办任务 |
| `activities` | 最近动态 |

> 具体字段结构在实现时补充；列表部分按 [conventions.md](./conventions.md) 分页或限量返回。

---

## 2. 指标规则

- 所有数据按当前用户的数据范围过滤
- `待我处理`：承办人是当前用户、状态为 `TODO` / `REJECTED` 的任务
- `逾期任务`：`dueAt` 已过且任务未通过
- `本月订单额`：本月创建且未取消的订单金额合计
